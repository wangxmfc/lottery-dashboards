大乐透是中国体育彩票发行的一种乐透型彩票。

🎱 前区：从1-35个号码中选择5个

💡 开奖时间：每周一、三、六晚上21:25

🏆 中奖规则

🏆 一等奖：5前+2后，浮动奖金（最高1000万）

🥈 二等奖：5前+1后，浮动奖金

🥉 三等奖：5前+0后，固定奖金10000元

🎖️ 四等奖：4前+2后，固定奖金3000元

🎖️ 五等奖：4前+1后，固定奖金300元

🎖️ 六等奖：3前+2后，固定奖金200元

🎖️ 七等奖：4前+0后，固定奖金100元

🎖️ 八等奖：3前+1后 或 2前+2后，固定奖金15元

🎖️ 九等奖：3前+0后 或 1前+2后 或 2前+1后 或 0前+2后，固定奖金5元

📝 术语解释
